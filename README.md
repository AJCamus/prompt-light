# Prompt Light 💡

A full-screen teleprompter that doubles as your camera light. Paste your script,
hit start, and read — the white screen itself is your fill light.

One file, no install, no dependencies. Open `prompt-light.html` in any browser.

## What it does

- **Paste & go** — paste text straight in, or open a `.txt` / `.md` file. Multi-page
  docs flow one after another; page breaks are stripped so there's no dead air.
- **Section tags pause the scroll** — any line like `[VERSE 1]`, `[CHORUS]`, or a
  `## Heading` is a section tag. When it reaches the red guide line, scrolling stops
  and a banner shows *"⏸ CHORUS — section 3 of 8 • Space to continue."* Take your
  break, hit Space, roll on. Or set auto-resume after 3 / 5 / 10 seconds — or never pause.
- **Full white screen** — white background, black text, so the screen lights your face.
  Font slider goes up to 120px, big and readable.
- **Speed controls everywhere** — a slider before you start, plus a live control bar
  while prompting (it fades away so it doesn't steal your light).
- **Mirror mode** — checkbox flips the text, in case you ever run it through prompter glass.
- **Progress bar** — thin bar up top so you know where you are in the script.

## Keyboard

| Key | Does |
|---|---|
| `Space` | Play / pause |
| `↑` / `↓` | Faster / slower |
| `←` / `→` | Nudge back / forward |
| `R` | Back to top |
| `F` | Full screen |
| `Esc` | Back to the editor |

## Use

Open the file, paste your script, press Start. That's the whole manual.
